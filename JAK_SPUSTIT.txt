1. PROČ SE ZIP SOUBOR PO ROZBALENÍ SÁM NESPUSTIL?
--------------------------------------------------------------------------------
Tato aplikace není jednoduchý statický soubor ani jednoúčelový program (.exe),
ale plnohodnotná full-stack webová aplikace (React + Tailwind + Express server
propojený s Google Gemini AI pro analýzu textu a OCR snímků).

Aby aplikace běžela na vašem počítači, potřebuje běhové prostředí Node.js.

================================================================================

3. JAK ROZJET ROZBALENÝ ZIP LOKÁLNĚ NA VAŠEM POČÍTAČI
================================================================================
Pokud chcete aplikaci spouštět z vlastního disku:

Krok 1: Nainstalujte si Node.js
- Stáhněte si bezplatný instalátor (doporučena verze LTS) z: https://nodejs.org/
- Nainstalujte (stačí klikat Next -> Next -> Finish).

Krok 2: Spuštění jedním klikem (ve Windows)
- V rozbalené složce dvakrát klikněte na soubor:
  spustit.bat
- Skript sám nainstaluje potřebné knihovny a otevře aplikaci v prohlížeči
  na adrese http://localhost:3000.

Krok 3 (alternativně ručně přes Terminál / Příkazový řádek):
- Otevřete příkazový řádek (CMD) v této složce.
- Napište: npm install
- Napište: npm run dev
- Otevřete prohlížeč na: http://localhost:3000
